# 「配置角色」字段清单

> 供字段提供方填写使用:以下为"配置角色"所需的全部字段与对应要求。

## 一、角色基本信息

| 字段 | 填入类型 | 是否必填 | 要求 / 说明 |
|---|---|---|---|
| 业务名称 | 文本框 | 必填 | 默认 `investment`;如 investment(投资咨询)、medical(医疗) |
| 角色类型 | 下拉选择 | 必填 | 二选一:`user`(普通用户)或 `ai_tool`(AI 工具角色);演示需至少一个 ai_tool |
| 角色名 | 文本框 | 必填 | 全场景唯一,不能为空;自动去除首尾空格 |
| 所属组织 | 文本框 | 选填 | 如:投资咨询中心 |
| 所在区域 | 下拉选择 | 必填 | 从地图区域中选择(可选范围见附录,共 12 项);坐标由系统自动分配 |
| 当前状态描述 | 文本框 | 选填 | 如:正在整理客户资产配置方案 |

## 二、职责与权限

| 字段 | 填入类型 | 是否必填 | 要求 / 说明 |
|---|---|---|---|
| 岗位 | 文本框 | 选填 | 如:首席投资顾问 |
| 职责 | 多行文本 | 选填 | 每行一条,或分号分隔 |
| 权限 | 多行文本 | 选填 | 每行一条,可含"可/不可"表述 |
| 规则/红线 | 多行文本 | 选填 | 每行一条 |

## 三、目标

| 字段 | 填入类型 | 是否必填 | 要求 / 说明 |
|---|---|---|---|
| 目标权重 | 多行文本 | 选填 | 每行 `目标:权重`,如 `收益最大化:0.6`、`风险规避:0.4`,权重总和应为 1;不填则自动等权分配 |

## 四、人设与习惯

| 字段 | 填入类型 | 是否必填 | 要求 / 说明 |
|---|---|---|---|
| 年龄 | 数字 | 选填 | 正整数,默认 35 |
| 先天性格 | 文本框 | 选填 | 如:谨慎、重视数据、情绪化 |
| 后天习得 | 文本框 | 选填 | |
| 生活习惯 | 文本框 | 选填 | |
| 日常计划概述 | 文本框 | 选填 | |

> 说明:**必填** = 该字段必须提供,否则无法生成角色;**选填** = 可留空,系统有默认处理。
