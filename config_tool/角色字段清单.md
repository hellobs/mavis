# 单一角色的字段清单

> 说明:**必填** = 该字段必须提供,否则无法生成;**选填** = 可留空,系统有默认处理。

## 一、角色配置:角色基本信息

| 字段 | 填入类型 | 是否必填 | 要求 / 说明 |
|---|---|---|---|
| 业务名称 | 文本框 | 必填 | 默认 `investment`;如 investment(投资咨询)、medical(医疗) |
| 角色类型 | 下拉选择 | 必填 | 二选一:`user`(普通用户)或 `ai_tool`(AI 工具角色);演示需至少一个 ai_tool |
| 角色名 | 文本框 | 必填 | 全场景唯一,不能为空;自动去除首尾空格 |
| 所属组织 | 文本框 | 选填 | 如:投资咨询中心 |
| 所在区域 | 下拉选择 | 必填 | 从地图区域中选择(可选范围见附录,共 12 项);坐标由系统自动分配 |
| 当前状态描述 | 文本框 | 选填 | 如:正在整理客户资产配置方案 |

## 二、角色配置:职责与权限

| 字段 | 填入类型 | 是否必填 | 要求 / 说明 |
|---|---|---|---|
| 岗位 | 文本框 | 选填 | 如:首席投资顾问 |
| 职责 | 多行文本 | 选填 | 每行一条,或分号分隔 |
| 权限 | 多行文本 | 选填 | 每行一条,可含"可/不可"表述 |
| 规则/红线 | 多行文本 | 选填 | 每行一条 |

## 三、角色配置:人物初始底色(IVD)

| 字段 | 填入类型 | 是否必填 | 要求 / 说明 |
|---|---|---|---|
| 初始倾向 | 多行文本 | 选填 | 每行 `目标:权重`,如 `Maximize Returns:0.8`、`Risk Aversion:0.2`,权重总和应为 1;决定倾向起点(人物底色),制度约束在治理面板另行配置;AI 工具角色可留空(出厂=制度约束) |

## 四、角色配置:人设与习惯

| 字段 | 填入类型 | 是否必填 | 要求 / 说明 |
|---|---|---|---|
| 年龄 | 数字 | 选填 | 正整数,默认 35 |
| 先天性格 | 文本框 | 选填 | 如:谨慎、重视数据、情绪化 |
| 后天习得 | 文本框 | 选填 | |
| 生活习惯 | 文本框 | 选填 | |
| 日常计划概述 | 文本框 | 选填 | |

## 五、关系录入

> 一条关系 = 角色A 与 角色B 之间的一组字段(见下表)。可提供多条关系,每条按同一格式填一份即可。

| 字段 | 填入类型 | 是否必填 | 要求 / 说明 |
|---|---|---|---|
| 角色A | 文本框 | 必填 | 已配置角色名,如:老周 |
| 角色B | 文本框 | 必填 | 已配置角色名,如:沈砚之 |
| 关系类型 | 文本框 | 必填 | 如:客户-顾问 |
| 方向 | 文本框 | 选填 | 如:老周→沈砚之(谁对谁) |
| 互动约定 | 文本框 | 选填 | 什么情境下触发互动,如:每天下午3点,老周找沈砚之咨询 |
| 频率 | 下拉选择 | 选填 | 三选一:`high` / `medium` / `low`,默认 `medium` |

## 六、剧情录入

> 一条剧情 = 一个独立事件(见下表)。可提供多条剧情,每条按同一格式填一份即可。

| 字段 | 填入类型 | 是否必填 | 要求 / 说明 |
|---|---|---|---|
| 触发时间 | 文本框 | 必填 | 格式 `HH:MM`(00:00–23:59),如 10:00 |
| 事件类型 | 文本框 | 必填 | 如:市场波动 |
| 事件内容 | 多行文本 | 必填 | 如:新能源板块盘中大幅波动,监管要求24小时内评估风险 |
| 重要性 | 数字 | 选填 | 1–10 的整数,默认 8 |
| 影响对象 | 文本框 | 选填 | 角色名逗号分隔,或填 `all`(全部角色),默认 `all` |
| 期望触发行为 | 文本框 | 选填 | 如:各角色评估风险,给出建议 |
